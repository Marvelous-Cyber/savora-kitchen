# Savora Kitchen 🍽️

A responsive website for **Savora Kitchen**, a fictional Nigerian restaurant. I built it as a portfolio project with plain HTML, CSS and JavaScript (no frameworks).

**Live demo:** https://Marvelous-Cyber.github.io/savora-kitchen/

## Features

- Responsive layout that works on phones, tablets and desktops
- Mobile hamburger menu and active-section highlighting while scrolling
- Menu generated from a JavaScript array, with category filter buttons
- "Order on WhatsApp" button on every dish (pre-filled message)
- Gallery with a pop-up viewer
- Contact form with validation (name, email, Nigerian phone number, message) that sends the message through WhatsApp
- Light and dark mode that follows the visitor's device setting
- Back-to-top button and an automatic copyright year

## Built with

- HTML5
- CSS3 (custom properties, grid, flexbox, media queries)
- Vanilla JavaScript

## Project structure

```
savora-kitchen/

```

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in a browser, or use the VS Code **Live Server** extension.

## Notes

- This is a demo. The restaurant, address, phone number and WhatsApp number are all made up.
- To use a real number, change the `WA` value at the top of `script.js` (country code, no `+`).
